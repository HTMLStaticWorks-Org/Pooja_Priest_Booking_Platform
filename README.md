# PoojaConnect — Pooja & Priest Booking Platform

A responsive, multi-page HTML/CSS/JavaScript front-end web application with authentic, realistic photography for sacred rituals, temples, and Vedic priests.

## Run
Open `index.html` or `home2.html` in any modern web browser. No build tools or server setup required.

## Pages
- `index.html` — **Home1**: Complete landing page featuring:
  - Hero with majestic South Indian temple photography
  - Auspicious trust metrics & statistics banner
  - Core Pooja Services grid with authentic photography
  - **Sacred Rituals Visual Gallery** (Deepa Aradhana, Vedic Havan, Kalash Sthapana, Vivaha, Chanting, Festivals)
  - **4-Step Booking Workflow** with visual cards
  - **Featured Verified Veda Priests** showcase with credentials and languages
  - **Pure Samagri & Preparation Kit Guarantee** banner
  - **Why PoojaConnect** trust pillars
  - **Devotee Testimonials & Real Celebrations** with verified customer reviews
  - **Frequently Asked Questions (FAQ)** section
  - Auspicious call to action
- `home2.html` — **Home2**: Alternate story-driven landing page featuring:
  - Elegant page hero with direct booking actions
  - The PoojaConnect Promise with authentic brass thali photography
  - **Upcoming Auspicious Festivals Calendar** (Diwali, Ganesh Chaturthi, Maha Shivaratri)
  - **Vedic Heritage & Shastra Verification Standards** with authentic chanting photography
  - 3-step simple ceremony planner
  - Devotee reviews and real celebrations
  - Free Muhurtham & Astrological Consultation banner
- `priests.html` — Certified Vedic Priest Directory with realistic pandit portraits, Veda Patashala credentials, languages, and ratings.
- `poojas.html` — 9 traditional ceremonies with realistic ritual photography (Griha Pravesham, Satyanarayan, Ganapathi Homam, Namakaran, Ayushya Homam, Wedding, Rudra Abhishekam, Navagraha Shanti, Lakshmi Kubera).
- `booking.html` — Booking request form with reassurance sidebar, samagri guarantee, and ceremony helpline.
- `about.html` — Mission and Vedic heritage preservation with authentic temple photography.
- `contact.html` — Enquiry form, ceremony helpline, social links, and OpenStreetMap embed.
- `login.html` / `signup.html` — Clean authentication views.

## Features
- **100% Realistic High-Resolution Photography**: All cartoon SVGs replaced with authentic Indian temple, pooja, havan, and priest photography stored locally in `assets/images/`.
- **Responsive Design**: Mobile-friendly grids for smartphones, tablets, and desktops.
- **Theme Support**: Seamless light and dark mode toggle with persistent local storage.
- **Bi-directional / RTL Support**: Native Right-to-Left layout toggle.
- **Pure Samagri & Muhurtham Guidance**: Transparent ceremony options for devotees.
