# PoojaConnect — Pooja & Priest Booking Platform

A responsive, multi-page HTML/CSS/JavaScript front-end concept.

## Run
Open `index.html` in a modern browser. No build tools or server are required.

## Pages
- `index.html` — Home1 (main landing page)
- `home2.html` — Home2 (alternate landing page)
- `priests.html` — priest directory
- `poojas.html` — pooja services
- `booking.html` — booking request form
- `about.html` — about
- `contact.html` — contact form, social links and OpenStreetMap embed
- `login.html` / `signup.html` — centered authentication cards

## Features
- Responsive navigation with Home1 and Home2 links
- RTL toggle and light/dark theme toggle in the navbar
- Theme and RTL preferences persist in local storage
- Authentication pages contain no images and keep cards centered
- Password show/hide control
- Local SVG artwork in `assets/` (works offline, no broken external image dependencies)
- Contact page includes an OpenStreetMap embed and social media links
- Demo forms show a confirmation message; connect a backend for real submissions

## Customisation
Edit `css/style.css` for styling, `js/main.js` for interactions, and page HTML files for content. Replace sample contact details and priest profiles before production use.
